# LayoutX2C 1.0.0

LayoutX2C 1.0.0 is the first stable release of the compile-time XML layout to
Kotlin generation pipeline. Supported XML is generated into code, while
unsupported or unsafe semantics continue through platform inflation instead of
breaking application builds.

## Highlights

- Stable runtime-facing API boundary marked with `@PublicApi` and
  `@ExperimentalApi`.
- Gradle plugin setup for Android application and library modules, including
  automatic KSP and runtime dependencies.
- Layout discovery through `@FastLayoutConfig`, `@FastLayouts`, and
  `@FastLayoutPattern`.
- Per-layout JSON reports and project-level HTML/JSON summaries for fallback
  visibility.
- Conservative fallback for unsupported nodes, include/ViewStub cases, and
  DataBinding semantics.
- Incremental generation cache keyed by layout and resource dependency digests.

```kotlin
    implementation("io.github.donglua.layoutx2c:runtime:1.0.0")

```
