# LayoutX2C 1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring LayoutX2C to a repository-ready 1.0 state following `docs/ROADMAP.md`.

**Architecture:** Keep runtime behavior conservative while tightening cache invalidation and documenting the public contract. Resource dependency scanning lives in `ksp-processor`, stable API markers live in `runtime`, and release readiness is expressed through Gradle metadata, CI workflow, ProGuard rules, and docs.

**Tech Stack:** Kotlin, Android Gradle Plugin, KSP, JUnit 4, Truth, Gradle publishing, GitHub Actions.

## Task 2: Implement ResourceDependencyScanner

**Files:**
- Create: `ksp-processor/src/main/kotlin/com/github/donglua/layoutx2c/ksp/ResourceDependencyScanner.kt`
- Test: `ksp-processor/src/test/kotlin/com/github/donglua/layoutx2c/ksp/ResourceDependencyScannerTest.kt`

- [ ] **Step 1: Add the scanner data model and SAX parsing**

Implement:

```kotlin
internal object ResourceDependencyScanner {
    data class Dependency(
        val key: String,
        val file: File?,
        val content: String
    )

    fun scan(layoutFile: File, resDir: File): Set<Dependency>
}
```

Use SAX for layout and values XML. Extract resource references matching
`@type/name`, skip `@+id`, `@id`, `@android:*`, and record unresolved references
as `Dependency(key = "unresolved:type/name", file = null, content = "UNRESOLVED")`.

- [ ] **Step 2: Resolve values resources conservatively**

Index `res/values*.xml` items by `type/name`. Include every matching qualified
definition in the dependency content. Recursively scan item text and attributes
for additional resource references.

- [ ] **Step 3: Resolve file resources**

For `drawable`, `mipmap`, and `color` references that resolve to non-values
files, include the relative path and file bytes converted to a stable SHA-256
hex string in `content`.

```kotlin
@Test
fun `layout digest ignores unrelated values resources`() {
    val first = digestFor(layout = """<TextView android:text="@string/title" />""")
    writeValues("""<resources><string name="title">Title</string><string name="unused">Before</string></resources>""")
    val before = digest()
```

- [ ] **Step 3: Replace coarse values hashing**

In `LayoutX2CDigestCalculator.layoutDigest`, remove the `valuesDir.walkTopDown()`
block. Add:

```kotlin
ResourceDependencyScanner.scan(layoutFile, resDir)
    .sortedWith(compareBy({ it.key }, { it.file?.relativeTo(resDir)?.invariantSeparatorsPath ?: "" }, { it.content }))
    .forEach { dependency ->
        digest.updateString("resource-dependency")
        digest.updateString(dependency.key)
        digest.updateString(dependency.file?.relativeTo(resDir)?.invariantSeparatorsPath ?: "NO_FILE")
        digest.updateString(dependency.content)
    }
```

Bump `SCHEMA_VERSION`.
